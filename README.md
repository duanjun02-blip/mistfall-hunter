# Mistfall Hunter Hub (fan wiki)

Static multi-page fan wiki for **Mistfall Hunter** (dark fantasy extraction ARPG, Bellring Games / Skystone Games, released Jul 30 2026).

- Pure HTML/CSS/JS, no build step → deploy to Cloudflare Pages / Vercel / GitHub Pages as-is
- English-first (multi-language planned)
- Dark fantasy gold/purple theme, HSL tokens in `assets/style.css`
- SEO: unique title/description/keywords per page, canonical, OG tags, sitemap.xml, robots.txt, one H1 per page
- All facts sourced (official site, Steam, SteamDB, Metacritic, Mobalytics, GameSpot, GamesRadar+, IGN, community wiki, Reddit); data snapshot 2026-08-07
